📖 Countable vs. Uncountable Nouns

✅ Countable Nouns (Contables)

Son cosas que podemos contar con números: 1, 2, 3...

  • 🍎 apple → one apple, two apples, three apples
  • 🍌 banana → one banana, two bananas
  • 🥚 egg → one egg, two eggs
  • 🍕 pizza → one pizza, two pizzas

❌ Uncountable Nouns (Incontables)

Son cosas que NO podemos contar con números. Usamos cantidades.

  • 🥛 milk → some milk, a glass of milk
  • 🍞 bread → some bread, a slice of bread
  • 🍚 rice → some rice, a bowl of rice
  • 💧 water → some water, a bottle of water

💡 Important:

With countable nouns, we use "There is" (singular) and "There are" (plural).

With uncountable nouns, we always use "There is".

📝 Affirmative / Negative / Interrogative

✅ Affirmative (Afirmativo)

Usamos "there is" (singular) y "there are" (plural).

  • 🟢 There is a banana on the table.
  • 🟢 There are five apples in the bowl.
  • 🟢 There is some milk in the fridge.

❌ Negative (Negativo)

Usamos "there isn't" (singular) y "there aren't" (plural).

  • 🔴 There isn't any bread at home.
  • 🔴 There aren't any eggs for breakfast.

❓ Interrogative (Interrogativo)

Usamos "Is there?" (singular) y "Are there?" (plural).

  • 🔵 Is there any milk in the fridge?
  • 🔵 Are there any apples in the basket?

📝 Remember:

🔹 There is → singular / uncountable

🔹 There are → plural

🔹 There isn't → negative singular

🔹 There aren't → negative plural

🔹 Is there? / Are there? → questions

🔧 A / An / Some / Any / A lot of

📌 A / An (singular)

Usamos con sustantivos contables en singular.

  • 🍎 an apple (vocal: a, e, i, o, u → an)
  • 🍌 a banana (consonante → a)

📌 Some (afirmativo)

Usamos con sustantivos contables en plural e incontables.

  • ✅ There are some apples on the table.
  • ✅ There is some milk in the fridge.

📌 Any (negativo / interrogativo)

Usamos con sustantivos plurales e incontables.

  • ❌ There aren't any eggs.
  • ❓ Is there any bread?

📌 A lot of (muchos / mucha)

Usamos con contables e incontables en afirmativo.

  • ✅ There are a lot of people.
  • ✅ There is a lot of water.

📝 Quick Guide:

🔹 a / an → singular countable

🔹 some → affirmative (plural / uncountable)

🔹 any → negative / question (plural / uncountable)

🔹 a lot of → affirmative (plural / uncountable)
